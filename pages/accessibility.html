Accessibility Statement

Last Updated: January 2026

Our Commitment

CORRIESELLS is committed to ensuring digital accessibility for people with disabilities. We continuously improve the user experience for all visitors and apply the relevant accessibility standards.

Accessibility Standards

We aim to comply with the World Wide Web Consortium's Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards. These guidelines explain how to make web content accessible to people with disabilities.

Accessibility Features

Keyboard Navigation

  • All website features are accessible using keyboard navigation (Tab, Enter, Escape)
  • Focus indicators clearly show which element is being accessed
  • No keyboard traps - users can move away from any element using keyboard alone

Screen Reader Support

  • All images have descriptive alt text for screen readers
  • Form labels are properly associated with input fields
  • Semantic HTML structure for proper content hierarchy
  • Compatible with NVDA, JAWS, and VoiceOver screen readers

Visual Accessibility

  • High contrast color scheme (white text on black backgrounds)
  • Font sizes are readable (minimum 14px body text)
  • Text is resizable without breaking layout (up to 200% zoom)
  • No content relies on color alone to convey information

Multimedia

  • All product videos include captions and transcripts
  • Audio content has text alternatives
  • No auto-playing audio or video that could be disruptive

Cognitive Accessibility

  • Clear and simple language throughout the website
  • Consistent navigation and page layout
  • Appropriate use of headings and sections
  • Simple and intuitive forms with clear instructions

Known Accessibility Limitations

While we strive for full accessibility, some third-party tools may have limitations:

  • Google Maps embed may have limited keyboard accessibility
  • Some embedded payment forms (Stripe, PayPal) may not be fully WCAG compliant
  • Image galleries may require mouse interaction (we're working on keyboard alternatives)

Accessibility Tools & Browser Extensions

We recommend these tools to enhance your browsing experience:

  • Screen Readers: NVDA (free), JAWS, VoiceOver (Mac/iOS)
  • Browser Extensions: Reader Mode, Color Contrast Analyzer, WAVE
  • OS Tools: Windows High Contrast Mode, macOS Dark Mode
